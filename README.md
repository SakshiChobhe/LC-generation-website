# LC-generation-website
A web application that generates Letter of Credit (LC) documents seamlessly. This platform simplifies the process of creating, managing, and verifying LCs for trade and business transactions.

Features
✅ Automated LC Generation – Generate accurate LC documents effortlessly.
✅ Secure & Transparent – Ensures data integrity and security.
✅ User-Friendly Interface – Simple and intuitive design for ease of use.
✅ Customizable Templates – Modify LC formats to fit business needs.
✅ PDF Export & Sharing – Download and share LCs with relevant parties.

Tech Stack
Frontend: HTML, CSS, JavaScript

Backend: PHP

Database: MySQL
